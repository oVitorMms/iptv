# IPTV Landing Page

Landing page desenvolvida como projeto de prática de desenvolvimento front-end, com foco em estruturação de páginas web, design responsivo e experiência do usuário.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Funcionalidades

- Navbar com navegação entre seções
- Seção inicial (Hero)
- Apresentação de benefícios
- Categorias de conteúdo
- Seção de planos
- FAQ com perguntas expansíveis
- Layout responsivo

## Objetivo

Praticar desenvolvimento front-end, organização de código e criação de interfaces modernas.
